# Нейро-нечеткая оценка стоимости недвижимости

Проект ВКР «Разработка нейро-нечеткой модели для оценки рыночной
стоимости объектов недвижимости».

## Цель

Разработать модель оценки стоимости жилья, сравнить её с базовыми
методами по MAE, RMSE и R² и исследовать возможности объяснения прогнозов.

## Текущая реализация

Предварительный Python-прототип на California Housing:
8 признаков -> 40 степеней принадлежности -> MLPRegressor.
Для сравнения используется MLP на стандартизированных исходных признаках.

Прототип не реализует ANFIS или оптимизацию базы правил.
Лингвистическое описание входов пока не является объяснением прогноза.

## Запуск

```bash
python -m pip install -r requirements.txt
python main.py
```

При первом запуске scikit-learn скачивает California Housing.
Скрипт выводит MAE, RMSE и R² для двух моделей, а также результаты
сравнения на пяти случайных разбиениях.
